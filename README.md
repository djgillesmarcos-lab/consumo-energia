## 📌 Objetivo

A Calculadora de Consumo Elétrico é um programa em Python que estima o consumo mensal de energia de um aparelho usando a potência e o tempo médio de uso diário.

## 🐍 Linguagem

- Python 3

## 🧮 Fórmula utilizada

```text
consumoMensal = (potencia × horasDia × 30) / 1000
